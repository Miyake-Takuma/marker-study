# Marker Study
完全無料で学習を楽にする。静的な学習PWAの公開用パッケージです。

site.zipにはHTML・CSS・JavaScript・アイコン・PDF/OCR用ライブラリのみを収録しています。ZIP内のコードは公開して読めます。開発元専用画面・個人PDF・学習記録・認証情報は含みません。

## 公開
GitHub FreeのPublicリポジトリに、このフォルダのsite.zipとREADME.md、.github/workflows/pages.ymlを配置します。
Settings → Pages → SourceをGitHub Actionsにします。ActionsのPublish Marker Studyが成功するとPagesにHTTPS URLが表示されます。
有料プラン・独自ドメイン・課金登録は不要です。サービスの規約・上限・継続条件には依存します。

## iPhone
公開URLをSafariで開き、共有 → ホーム画面に追加 → Webアプリとして開く（表示される場合）→ 追加。
暗記・テスト・手動編集・問題集JSONの受け渡しが利用できます。PCの端末内AIはiPhoneでは動きません。
オフライン準備完了を確認してからオフラインで利用してください。iPhone実機での確認は公開後に必要です。

データは端末・ブラウザごとに保存され、自動同期されません。移行前にバックアップを保存してください。
第三者ライブラリのライセンスは公開アプリのTHIRD-PARTY.mdおよび各同梱ライセンスを参照。
